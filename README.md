# 좀 씻어라 (2단계 최종 프로토타입)
앱 이름 「좀 씻어라」 / 부제 「씻는 거, 오늘도 한 번만 챙겨요」. 정적 HTML 시안, `index.html` 열면 동작(빌드 없음).
미리보기: https://kimjubo.github.io/jom-wash-prototype/
- 흐름: 인트로 그림(눌러서 시작) → 홈(유형 선택) → 오늘 체크 / 순서 가이드·타이머 / 씻겨주기(반려견·반려묘·아기·어르신).
- 문구·내용은 모두 `data.js`. 그림 경로는 `data.js`의 `art`. 파일을 바꾸면 `data.js`의 `version`과 `index.html`의 `?v=`를 함께 올림.
- 비어 있음(검증 전): 어르신 빈도·세정제 수치, 욕조 의자 관련 문구. 어린이·몸이 불편한 가족은 준비 중.
- 아이사랑(childcare.go.kr) 링크는 박스에서 열리지 않아 미확인.
- 푸시 알림 없음. 광고 버튼은 자리표시(SDK 미연결), 핵심 기능은 광고 없이 동작.
- 모든 내용 reviewed:false (전문가 검수 전). 앱인토스 배포본 아님.
