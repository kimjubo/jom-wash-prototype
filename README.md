# 씻는 거, 오늘도 한 번만 챙겨요. (1차 시안)
정적 HTML 시안. `index.html` 열면 동작. 화면 4개: 유형선택(home) / 오늘체크(check) / 순서가이드·타이머(guide) / 씻겨주기(care).
- 문구·내용은 모두 `data.js`. 새 대상은 `care.targets`에 항목 추가(ready:true + 내용), 어린이·몸이 불편한 가족은 ready:false(준비 중).
- 수치(물 온도·시간·샴푸)는 `care.numbers`가 비어 있음. 출처 링크를 `source`에 넣은 뒤에만 value 입력.
- 모든 내용 reviewed:false (출처·전문가 검수 전). 푸시 알림 없음. 광고 버튼은 자리표시(SDK 미연결), 핵심 기능은 광고 없이 동작.

> 앱인토스 미니앱 「좀 씻어라」 미리보기용 프로토타입, 시안, 심사·출시 전, 안전 수치는 출처 확인 전이라 미입력

> **미리보기 용도 안내**: 이 저장소는 앱인토스 배포본이 아니라 화면 확인용 시안입니다. 광고 버튼은 실제 광고가 아닌 자리표시(SDK 미연결)입니다.
